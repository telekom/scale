## Evidence And Scope

- Per-component JSON reports include status, test titles, theme outcomes, attachments, and test-file `sourceHash` provenance. Each component directory contains `contract.md`; executed cases retain uniquely prefixed screenshot PNGs, trace ZIPs, and accessible-state text files under `packages/visual-tests/interaction-results/components/<component>/`. The JSON maps each test to these files. Generated evidence links work after a local run or in the downloaded CI artifact; generated files are not committed.
- Assertion audit passed: checks use real Storybook controls and user input, and verify relevant accessible/rendered state, host state, or public events and payloads as appropriate. Test instrumentation observes emitted browser events; it is not used as a substitute for product state.
- The interactive report is [interaction-report/index.html](../packages/visual-tests/interaction-report/index.html). Local and CI instructions are in [the visual-test guide](../packages/visual-tests/README.md).
- Known gaps: Menu disabled-item traversal and Escape focus restoration; Slider Home/End; Segmented Button boolean `aria-pressed` representation and initial-mount sizing; Notification Badge keyboard activation.
- Visual regression passed all 478 active cases; the 54 skipped legacy cases remain excluded as before. Snapshot policy passed, and committed baselines were not changed. Human design approval is not implied. Remote CI confirmation is recorded on the PR, not assumed from local results.
- All 38 per-component agents were asked to use GPT-6 Luna through the tool model parameter. Runtime model identity was not independently verified.
