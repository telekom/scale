## Review Summary

**Specification:** Four duplicate visual assertions were removed: Dropdown Select Escape and host-disabled behavior, Sidebar Navigation keyboard behavior, and the Segmented Button disabled-state case. Private Data Grid sizing guards and the original Segmented Button clone/remount setup were removed. Sidebar Navigation now changes a nested child's label and `href` at runtime, checks its `aria-current` state, follows the updated link, and verifies pointer-driven branch state. Notification Badge callback readiness uses the public rendered label as a readiness marker and a synchronous callback observer, not a test-owned click marker.

Known product gaps remain outside this test-only change: Menu disabled-item traversal and Escape focus restoration; Slider Home/End support; Segmented Button boolean ARIA state and amount sizing; Notification Badge keyboard operation; and Accordion parent-property inheritance for children added after load. The Accordion implementation propagates `headingLevel` and `iconLocation` to current children, but does not observe later child additions.

**Standards:** The four CI findings are addressed: explicit `contents: read` permissions; validation that both configured light and dark projects exist even when configuration is reduced; cache keys that include root and workspace manifests plus `yarn.lock`; and a frozen, non-interactive bootstrap. The local structured workflow check and remote CI remain pending. Runtime verification of the bootstrap remains pending. One P3 remains: the legacy new-file header guidance in `CONTRIBUTING.md` conflicts with the current JavaScript suite style; no header was added. No runtime-standard finding was identified.
